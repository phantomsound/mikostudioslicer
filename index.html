Miko Studio Slicer • Help & Walkthrough

Master guides, architectural coloring, and cloud workflows

Studio Workflow in 3 Simple Steps

Miko Studio Slicer bridges raster artwork, vector tracing, and broadcast graphics into a unified desktop pipeline:

1. Deconstruct (Tab 1)

Load your image, extract brand palettes, run AI background removal (U2Net), and crop out regions.

2. Canvas Studio (Tab 2)

Arrange vector paths, apply Behr paint colors, use Paint Bucket fill, toggle Studio Glow, and adjust layer hierarchy.

3. Broadcast & Export (Tab 3)

Generate broadcast 1080p Lower Thirds, export live animated OBS overlays, or package layered SVG & PSD files.

Behr & Home Depot Style Color Visualizer

Inspired by architectural color apps like Behr ProjectColor, you can now recolor individual items on your canvas with zero friction:

  • Bucket (K) Select the Paint Bucket tool from the toolbar and click directly on any shape, text, or vector path to flood fill it with your active color.
  • Hue Slider Drag the 0°–360° Hue Slider in the inspector to rotate the color temperature and hue of your selected palette in real time.
  • Cycle (C) Hit the "Cycle Colors" button or press keyboard shortcut C to quickly audition every color in the selected designer theme on your active selection.
  • Studio Glow Check "Studio Highlight Glow" on any layer to add customizable neon or stage lighting with adjustable blur and radius.

AI Cutout & VTracer Precision Vectorization

Seamlessly transform photographs, architectural elevations, and artwork into clean vector layers:

• AI Background Cutout: Powered by U-2-Net neural network to isolate subjects with anti-aliased alpha borders.

• Vector Separation Studio: Choose from 2 to 16 color layers with spline or polygon curves. Check "Snap to Brand Colors" to automatically conform tracing to your curated palette.

• Magic Cleanup Eraser (E): Hover over any unwanted curve or path to see a red highlighted preview, then click to erase it even deep within nested groups!

Project Files (.mikoproj) & Cloud Sharing

Keep your project data intact with versioned project packages and 1-click cloud sync:

• Data Integrity: Saving with Ctrl+S writes an enriched .mikoproj envelope bundling canvas dimensions, object hierarchy, locked layer flags, and brand color swatches.

• Cloud Drives: Click the "Share" button or open the File > Cloud & Share menu to instantly launch Google Drive, Microsoft OneDrive, or Dropbox with your project file ready to upload.

• Direct Device Share: Uses the native Web Share API to send projects via AirDrop, Quick Share, or team chat apps.
